## Abstract

SketchBloom is a training-free framework for text-guided vector sketch outpainting with stroke-level style control. Given a sparse input sketch, a text prompt, and an optional reference style image, SketchBloom extends the sketch beyond its original boundary while preserving the sketch domain.

The method transfers the reference style's stroke width, color, and texture distribution through adaptive latent blending. It then converts the result into a resolution-independent SVG composed of optimized Bézier strokes. By separating structural contour strokes from free-form texture strokes and compositing them with multiply blending, SketchBloom produces editable vector outputs that preserve both scene structure and stylistic identity.

</HighlightedSection>

## What SketchBloom Does

SketchBloom addresses a gap between raster diffusion outpainting and editable vector graphics. Existing raster outpainting methods can extend images, but they usually output fixed pixels. Existing vector sketch methods often generate from scratch rather than extend an existing sketch.

SketchBloom combines three capabilities in one training-free pipeline:

- **Sketch outpainting:** extends a sparse input sketch using a text prompt.
- **Reference-guided style control:** transfers stroke-level visual identity from a reference image.
- **Editable SVG generation:** produces scalable Bézier strokes instead of fixed raster pixels.

### Stage 1: Raster preprocessing and adaptive latent blending

SketchBloom first uses a ControlNet-conditioned diffusion model to semantically extend the input sketch into a full-content raster image. It then extracts contours and applies reference-guided style transfer through DDIM inversion, AdaIN initialization, and adaptive latent blending.

This stage produces a stylized raster target that guides the later vector optimization stage.

### Stage 2: Differentiable stroke initialization and optimization

SketchBloom initializes Bézier strokes through a hybrid tiling strategy. Contour-guided placement preserves important structural lines, while attention-guided sampling improves coverage in semantically important regions.

The system then optimizes two stroke sets separately:

- **Structure strokes:** preserve dark contour geometry.
- **Texture strokes:** capture shading, hatching, and loose stylistic detail.

### Stage 3: Layer-wise vector fusion

The final SVG is produced by compositing the structure and texture stroke sets using a multiply-blend layering scheme. This preserves dominant contour lines while retaining style-specific texture and shading.

## SketchBloom-Bench

We introduce **SketchBloom-Bench**, a benchmark for evaluating style-guided vector sketch outpainting. It contains 1,024 input-style combinations by pairing outpainted content images with diverse reference styles. The benchmark covers multiple sketch categories and reference styles ranging from minimal contour drawings to dense cross-hatching, graphite shading, and loose ink-wash styles.

## Responsible Use and Limitations

SketchBloom is intended as a creative-assistance tool for illustrators, concept artists, and designers. Since the method can transfer the visual vocabulary of a reference image, users should avoid imitating the distinctive style of living artists without permission.

We recommend using references from one's own work, public-domain material, appropriately licensed images, or images with explicit permission. Generated outputs should be treated as editable drafts for human refinement rather than final human-authored artwork.
